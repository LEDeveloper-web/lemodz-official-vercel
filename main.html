Admin Abuse 2

Mod Version: v1.1.0

  • 10 Ranks
  • 10 Skills
  • 50 Fruits
  • Rank Shop
  • Bedrock 1.21+

Major update. 10 ranks (recruit → owner) + staff tags, 10 skills (0–10), Rank Shop (1000 products), Item Shop (50 tools/gear/trolls), Fruit Shop (50 Blox-style fruits with abilities), daily rewards, bank system, and Owner/Admin power via control tag. Help: /le:ahelp or /ahelp.

Requirements

  • Minecraft Bedrock Edition 1.21+
  • Experiments → Beta APIs = ON
  • Import LEAdminAbuse-v1.1.0.mcaddon
  • Enable Behavior Pack + Resource Pack

How to use

  1. Join the world.
  2. Run /tag @s add control
  3. Run /le:setrank @s owner
  4. Open help with /le:ahelp or /ahelp
